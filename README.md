# Postavitve za uporabniški vmesnik

Funkcionalnosti:
<ul>
  <li>Toast – prikaže kratko obvestilo.</li>
  <li>Count – poveča števec in spreminja barvo gumba glede na sodo ali liho vrednost.</li>
  <li>Zero – ponastavi števec na 0 in barvo ozadja gumba vrne na sivo.</li>
  <li>Ob kliku na Count se spremeni tudi barva gumba Zero.</li>
</ul>

Uporabljene tehnologije:
<ul>
  <li>Java</li>
  <li>XML</li>
  <li>Android Studio</li>
  <li>ConstraintLayout</li>
</ul>

Uporabniški vmesnik je prilagojen pokončni in ležeči orientaciji in večjim zaslonom (land, xlarge).
